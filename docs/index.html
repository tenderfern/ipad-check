tenderfern iPad check

Test pages for an embedded player on an iPad whose Screen Time allows only listed websites. What a test learns is written on the screen, because this iPad has no desktop inspector attached.

The pages are published at https://tenderfern.github.io/ipad-check/. The allowlist entry for the site is exactly tenderfern.github.io. Never github.io: that entry would allow every site published on GitHub Pages.

Nothing here is the child app. The pages hold nothing about a child, store no copy of a video, and load nothing from any host but this site until the player page is asked to load a mode.

Pages

  • Procedure — the run order, and what to record at each step.
  • Player — three embed modes, the video set, a log of every event, and a button for a sign-in prompt.
  • Storage — whether a token survives in a Safari tab and in a home-screen web app.
  • Results — the form for each run and question, kept on this device, exported as Markdown.
  • Hosts — a desktop page that reads a HAR file locally and lists hosts. Nothing is uploaded.
