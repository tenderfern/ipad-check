Hosts

For a desktop browser. Choose a HAR file. This page lists each host with its request count and resource types. The file is read here and is not uploaded.

A HAR can hold cookies and headers. Do not commit it. Copy the host list into the results note, and keep the file off the repository.

Getting a HAR

  1. In the desktop browser, open developer tools, then Network.
  2. Turn on Preserve log and Disable cache.
  3. On the published site, play each test video in each mode.
  4. Export HAR (sanitized).

That list is a starting point for question 1, the domains the allowlist needs. The run itself is on the iPad: add hosts one at a time, as the procedure says.

The sample, har-sample.json, is made up. Its headers are not a real capture, and it has no real cookie. It is only for checking this page.
