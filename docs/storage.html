Storage

A token and the time it was written, in localStorage, IndexedDB, and a cookie this page sets itself. The cookie asks to live 400 days. Safari may ignore that.

All three copies are written by script. Safari can delete a site's script-written storage after seven days without a visit. Come back after about one day, three days, and eight days, and read which copies are still here and how old they are.

GitHub Pages cannot set a cookie from the server, so this result is a lower bound. The product's own server could use an HttpOnly cookie, which this page cannot set and would not be able to read.

A Safari tab and a home-screen web app keep separate storage. This page says which one it is open in.
